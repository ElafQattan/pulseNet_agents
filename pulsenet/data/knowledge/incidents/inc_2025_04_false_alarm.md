# INC-2025-04: door alarm at a site during planned maintenance

**What happened.** A site cabinet door alarm triggered an urgent security dispatch. It was a contractor with a valid
work order.

**Lesson.** Check the logs for a work order before escalating. A door alarm with a matching work order is low
priority and needs no action.
